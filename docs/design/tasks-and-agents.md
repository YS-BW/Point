# 任务、目标与 Agent

> 更新：2026-10-18。Agent 执行统一使用 Pi Durable。产品任务与 Durable Task 分别表达业务工作和运行进度。

## 概念与映射

| 概念 | 含义与承载 |
|---|---|
| 主会话 / 主题侧聊 | 用户可持续交互的聊天，各自映射一个 Durable conversation |
| Goal | 跨多次任务的长期意图、约束与期望结果；Point document 保存，完整模型待实现 |
| 产品 Task（原型中称 job） | 有明确结果的一项工作，记录要求、版本、状态、产物、所属/来源聊天和后续安排 |
| Durable Task | 运行时的持久状态机；包括内置 generation/tool 和 Point 的 Work/Report/Share/Followup/Lease |
| 执行会话 / 子 Agent | 任务内部的模型与工具上下文，映射 task-owned conversation；不是另一个执行引擎 |

用户待办可能是由用户完成的承诺，不意味着 Agent 要代为执行该动作。Agent 可为其创建准备工作。长期目标空闲时保存状态，按事件或时间再推进，不用永远运行模型。

## 协作与生命周期

主 Agent 在 main 或侧聊处理普通对话、查记忆、更新事项和协调工作。短工具操作直接执行；较长或独立工作才委派，立即返回任务 ID，让聊天继续响应。

后台工作创建产品任务、Durable Work task 与内部执行会话，保存相互引用。委派传递任务、约束、相关历史/引用；可从完整消息边界 fork，但不把浏览器句柄、整个共享状态或所有历史无条件复制给任务。

- 同一任务的补充要求、追问执行和恢复沿用任务身份与上下文；独立任务有独立上下文。
- 研究、代码、浏览器等是可复用角色/工具配置，不是永久运行的固定成员。
- 内部执行会话由 Work task 管理，任务链的取消按 ownership 传播。用户可见侧聊由聊天目录管理，不能随委派任务结束一起删除。
- 完成后保存结果和产物引用，停止执行并保留记录；需要继续时由产品明确恢复或创建后续工作。
- 多个独立任务可并行；同一会话的输入遵循 Durable 的 busy/排队语义；共享浏览器、文件和预算另做并发控制。
- Agent 可以内部拆步骤，不能把每个推断步骤都变成用户的新承诺。

产品状态至少区分待执行、执行中、等待用户、成功、失败、取消；计划状态独立保存。`unknown` 描述外部动作/投递结果不明，任务此时可能等待核查，不能直接算成功或盲目重做。最终枚举与 API 在正式 Server 固化，不要求逐一复制运行时状态。

## 任务状态与结果回传

Point document 是产品任务的权威，Durable Task/checkpoint 是执行进度的权威，以 ID 和要求版本关联。业务完成、报告记录、待回传任务和后续计划尽量同事务创建。文件先完成写入/核对，再提交产物引用；文件系统不属于数据库原子事务。

结果先回所属聊天；侧聊任务默认不打扰 main。用户要求 main 摘要或任务由 main 委派到侧聊时，可同时回 main。归档后的新结果转入 main，保留原来源。回传作为带稳定请求 ID 的输入进入目标 Agent，使后续追问能使用结果，不只显示一条 CLI 日志。

## 修改、停止与恢复

| 操作 | 作用域与契约 |
|---|---|
| 补充要求 | 更新产品任务版本；当前轮结束后处理新版；投递前核对版本，旧结果不得冒充新要求的完成 |
| 停止回答 | 停止当前聊天的执行，不取消独立后台任务 |
| 取消任务 | 取消其 Work/回传/跟进链与待处理通知，释放所属资源；不撤销已发生的外部动作 |
| 改期 | 替换计划并使旧版本失效；必要时调整正在做的准备 |
| 归档主题 | 隐藏/停止新输入，保留历史与后台工作；不是取消任务 |
| 人工接管 | 暂停对应浏览器的 Agent 输入，其他独立工作继续 |
| 重启 | 恢复同一任务与执行会话；先核查外部动作未知状态和远端浏览器存活情况 |

等待客户端连接、等待未来时间、等待用户与执行失败要分别表达。不能用一个长期阻塞的 HTTP 请求代替后台任务。已进入模型队列的消息或已发出的动作不能靠取消记录回滚。

## 长期工作与后续验收

长期能力由持久任务、checkpoint、时间/事件唤醒和进程常驻共同构成。模型输出质量、任务拆解和真正完成仍需 Point 的验收标准与策略；Durable 不自动成为完整 Goal 规划器。

当前原型验证了后台执行、补充/取消、同上下文恢复、回传与一次跟进。周期目标、自动选择下一步、等待用户后的自动续作、长期成本/重试上限仍需实现和验证。不再把 Goal/调度终端插件作为任务系统的前置依赖。
